# 🚗💨 방구차 게임 (Fart Car Game)

재미있는 아케이드 스타일의 방구차 게임입니다! 뒤에서 쫓아오는 차들을 방구로 막아내며 최대한 오래 살아남으세요!

## 🎮 게임 방법

1. **이동**: 키보드 화살표 키 (← →) 또는 A/D 키로 좌우 이동
2. **방구 발사**: 스페이스바 또는 화면의 "💨 방구!" 버튼을 눌러 방구 발사
3. **목표**: 뒤에서 쫓아오는 적 차량을 피하거나 방구로 격파하며 최대한 높은 점수를 획득하세요!

## 🎯 게임 규칙

- **점수 획득**:
  - 적 차량을 피해서 화면 밖으로 보내면: **+10점**
  - 적 차량을 방구로 파괴하면: **+50점**

- **게임 오버**: 플레이어 차량이 적 차량과 충돌하면 게임이 종료됩니다

- **난이도**: 시간이 지날수록 적 차량이 더 자주 나타납니다

- **방구 쿨다운**: 방구는 발사 후 잠시 쿨다운이 필요합니다 (화면 좌측 상단에 표시)

## 🚀 게임 실행 방법

1. `fart-car-game.html` 파일을 웹 브라우저에서 열기
2. "게임 시작" 버튼 클릭
3. 즐기기!

```bash
# 로컬에서 바로 열기
open fart-car-game.html  # macOS
xdg-open fart-car-game.html  # Linux
start fart-car-game.html  # Windows
```

또는 간단한 로컬 서버로 실행:

```bash
# Python 3
python -m http.server 8000

# 브라우저에서 http://localhost:8000/fart-car-game.html 접속
```

## 🎨 게임 특징

- 🎮 간단하고 중독성 있는 게임플레이
- 🌈 화려한 색상과 부드러운 애니메이션
- 💨 방구 파티클 효과
- 💯 점수 및 최고 점수 시스템 (로컬 스토리지에 저장)
- 📱 모바일 터치 버튼 지원
- 🎯 적 차량 체력 시스템
- 🚗 점점 증가하는 난이도

## 🔧 기술 스택

- HTML5 Canvas
- Vanilla JavaScript
- CSS3 (그라디언트, 애니메이션)
- LocalStorage (최고 점수 저장)

## 📝 게임 메커니즘

이 게임은 PuPu Car와 유사한 게임 메커니즘을 기반으로 제작되었습니다:
- 플레이어가 도로에서 차를 운전
- 뒤에서 적 차량들이 추격
- 방구(배기가스)를 발사하여 적 차량을 느리게 하거나 파괴
- 생존 시간과 처치 수에 따라 점수 획득

## 🎯 게임 팁

1. 방구는 쿨다운이 있으니 신중하게 사용하세요!
2. 모든 적을 방구로 맞출 필요는 없습니다 - 피하는 것도 전략입니다
3. 적 차량은 3번의 방구 공격을 맞아야 파괴됩니다
4. 시간이 지날수록 더 많은 차량이 나타나므로 집중하세요!
