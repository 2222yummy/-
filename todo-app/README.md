# 스마트 할일 관리 앱

할일을 입력하면 자동으로 카테고리를 분류해주는 Todo 앱입니다.

## 주요 기능

- ✨ **자동 카테고리 분류**: 할일 내용을 분석하여 자동으로 적절한 카테고리를 할당
- 📋 **카테고리별 필터링**: 7가지 카테고리(업무, 학습, 건강, 가사, 쇼핑, 취미, 기타)로 할일 분류
- 💾 **로컬 스토리지**: 브라우저에 자동 저장되어 새로고침해도 데이터 유지
- ✅ **완료 체크**: 할일 완료/미완료 상태 관리
- 🎨 **모던한 UI**: 그라데이션 배경과 직관적인 사용자 인터페이스

## 카테고리 분류 예시

앱은 다음과 같은 키워드를 인식하여 자동으로 카테고리를 분류합니다:

- **업무**: 회의, 미팅, 보고서, 프레젠테이션, 이메일 등
- **학습**: 공부, 학습, 강의, 수업, 과제, 독서 등
- **건강**: 운동, 헬스, 요가, 조깅, 병원 등
- **가사**: 청소, 빨래, 설거지, 요리, 정리 등
- **쇼핑**: 장보기, 쇼핑, 구매, 주문 등
- **취미**: 영화, 드라마, 게임, 여행, 음악 등
- **기타**: 위 카테고리에 해당하지 않는 항목

## 기술 스택

- React 19

## 시작하기

### 설치

```bash
npm install
```

### 개발 서버 실행

```bash
npm run dev
```

### 빌드

```bash
npm run build
```

### 프리뷰

```bash
npm run preview
```

## 사용 방법

1. 입력창에 할일을 입력합니다 (예: "회의 준비하기", "영어 공부", "운동하기")
2. "추가" 버튼을 클릭하면 자동으로 카테고리가 분류됩니다
3. 카테고리 필터 버튼을 클릭하여 원하는 카테고리의 할일만 볼 수 있습니다
4. 체크박스를 클릭하여 할일을 완료/미완료 상태로 변경할 수 있습니다
5. 🗑️ 버튼을 클릭하여 할일을 삭제할 수 있습니다
